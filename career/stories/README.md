## 怎么用
- 每个 `.md` 文件是一个故事，头部 `tags:` 决定它匹配哪类 JD/面试题。
- `[方括号]` 是留给你补充的真实数字/细节——**只填真实的**，宁可删掉也不编造。
- Cover letter 生成（`src.tailor`）和面试准备（`src.interview prep`）会自动挑选
  与 JD 最相关的故事注入。
- 面试后有新的好素材 → 加新故事文件或充实现有的。
